# Base de données PostgreSQL

## Description
Scripts SQL et migrations pour la base de données PostgreSQL.

## Tables principales
- users
- patients
- consultations
- symptoms
- analyses
- diagnostics
- treatments
- logs

## Installation
1. Installer PostgreSQL
2. Créer la base de données
3. Exécuter les scripts de création
4. Exécuter les migrations

## Scripts
- `schema.sql` : Schéma complet de la base
- `migrations/` : Migrations versionnées
- `seeds/` : Données de test
